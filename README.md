An entry for the make.fun bounty **Tell a Whole Story in 32 Characters**: one Wi-Fi network name that lands a joke and implies a whole story in the few words a passer-by sees in a phone's network list.

## The story

> The WiFi outlived the marriage

A marriage ended. The network is still here. The name is the punchline: the Wi-Fi outlived the marriage, and every passer-by can fill in the rest — who left, who kept the router, and what the password used to be.

## What it does

`main.ts` writes the 30-character story to `/output/entry.txt`, after checking it is 1 to 32 characters and not only white space.

## How to run

Requires Node 22 or later:

```sh
node main.ts
cat /output/entry.txt
```
